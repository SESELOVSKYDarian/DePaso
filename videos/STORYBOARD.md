| Tiempo | Plano y texto | Locución |
|---|---|---|
| 0–5 s | hook. ¿Y si ahorrar / te quedara / de paso? | ¿Y si ahorrar te quedara de paso? |

## funciones · 1920×1080 · 180 s

| Tiempo | Plano y texto | Locución |
|---|---|---|
| 0–7 s | brand. Tu compra. / Tu recorrido. | Conocé DePaso, la app que te ayuda a decidir dónde comprar según tu lista y tu recorrido. |
| 7–15 s | ui · login. Empezá / con tu cuenta. | Entrá con email, Google, Meta o Discord. También podés recuperar tu contraseña. |
| 15–23 s | ui · lists. Una lista para / cada compra. | Creá una lista para cada compra. Poné un nombre que reconozcas y abrila para empezar a sumar productos. |
| 23–31 s | ui · search. Encontrá / lo que buscás. | Buscá productos por nombre y afiná con filtros de tipo y marca. Sumalos a tu lista desde los resultados. |
| 31–38 s | ui · list. Tu lista. / En equipo. | Ajustá cantidades, quitá productos y compartí la lista con otra persona que también use DePaso. |
| 38–44 s | ui · voice. Armarla / puede ser fácil. | Con el asistente, podés decir de corrido todo lo que te falta comprar. |
| 44–50 s | ui · voice-review. Revisá antes / de sumar. | Revisá los productos, elegí marcas y confirmá. También podés escribir. |
| 50–59 s | ui · places. Tus lugares. / Siempre a mano. | Guardá tus lugares habituales, como casa y trabajo. Así podés armar nuevos recorridos sin volver a cargar las direcciones. |
| 59–67 s | ui · route. Elegí por dónde / vas a pasar. | Elegí un recorrido guardado o armá uno nuevo con las paradas de tu día. Podés usar tu ubicación actual. |
| 67–74 s | map. La compra / en tu camino. | El mapa te permite ubicar tu recorrido y las paradas de compra. Todo en un mismo contexto. |
| 74–80 s | ui · detour. ¿Cuánto / te desviás? | También elegís cuántas cuadras aceptás desviarte para las opciones sin desvíos e intermedio. |
| 80–89 s | ui · payments. Pagá a / tu manera. | Marcá tus billeteras y tarjetas. DePaso considera sus promociones según el comercio y el día, con las condiciones que correspondan. |
| 89–97 s | ui · optimization-setup. Lista + recorrido. / A comparar. | Para comparar, elegí una lista con productos y confirmá el recorrido. Después, tocá Ver mi Top tres. |
| 97–107 s | ui · plans. Hasta tres formas / de comprar. | Las opciones son sin desvíos, intermedio e hipereconómico. Compará el costo, las paradas y la distancia extra antes de elegir. |
| 107–115 s | ui · best-prices. Compará también / por producto. | En Mejores precios, mirá dónde está más barato cada producto. Los precios son orientativos: confirmalos en el comercio. |
| 115–124 s | ui · purchase. Tu compra, / por comercio. | Al tocar Empezar compra, los productos se organizan por comercio. Tenés cantidades y precios a mano durante la compra. |
| 124–132 s | ui · purchase-check. Marcá. / Completá. Listo. | Marcá cada producto a medida que lo comprás. Cuando completás la lista, se habilita la opción para finalizar. |
| 132–140 s | ui · purchase. ¿Cambió / un precio? | Si encontrás otro precio, podés reportarlo desde la compra. Los aportes de la comunidad pasan por un proceso de verificación. |
| 140–149 s | ui · activity. Enterate / de las novedades. | En Actividad encontrás novedades del equipo y avisos para vos: listas compartidas, bajas de precio y oportunidades cerca de tus lugares. |
| 149–158 s | ui · profile. A tu gusto. / Bajo tu control. | Desde tu perfil configurás marcas, comercios, apariencia y notificaciones. También accedés a ayuda y a las opciones de privacidad de tus datos. |
| 158–166 s | ui · merchant-request. ¿Tenés / un comercio? | Los comercios pueden solicitar su perfil. Después de la aprobación, publican y actualizan sus productos y precios. |
| 166–174 s | ui · admin. Una comunidad / con respaldo. | La administración gestiona solicitudes y novedades. Su panel permite gestionar comercios y moderar reportes de precios. |
| 174–180 s | end. Descargá DePaso | Descargá DePaso. Tu compra, en el camino. |
